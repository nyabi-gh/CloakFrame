Detection models  (not bundled; downloaded when the user asks)
--
The built-in models are not committed to the CloakFrame repository or bundled
with its packages. CloakFrame shows each model's terms and, when the user asks,
downloads it from its pinned upstream location, verifies its SHA-256 digest, and
keeps it in the app's model folder. Their terms are separate from CloakFrame's
license; confirm the upstream terms before commercial use or redistribution.

YOLO5Face-n (recommended face detector)
  ONNX conversion from the yolov5-face-onnx-inference release:
  https://github.com/yakhyo/yolov5-face-onnx-inference/releases/tag/weights
  It is based on YOLO5Face (https://github.com/deepcam-cn/yolov5-face), whose
  code is GPL-3.0, and was trained on the WIDER FACE dataset, which is
  restricted to non-commercial research use. Treat this model as
  non-commercial only.

YuNet (fast face detector)
  face_detection_yunet_2023mar.onnx from the OpenCV Zoo:
  https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet
  That directory identifies the model license as MIT.

License-plate detector
  From open-image-models (https://github.com/ankandrew/open-image-models),
  which is MIT-licensed. It uses the YOLOv9 architecture and remains subject to
  its upstream project's terms.

Citations
  Qi, Tan, Yao, Liu. YOLO5Face: Why Reinventing a Face Detector.
    arXiv:2105.12931, 2021.
  Wang, Liao. YOLOv9: Learning What You Want to Learn Using Programmable
    Gradient Information. arXiv:2402.13616, 2024.

FFmpeg 9.0.2 with x264 and x265  (bundled as the ffmpeg and ffprobe programs; reads and writes videos)
--------------------------------------------------------------------------------
CloakFrame packages include ffmpeg and ffprobe, which CloakFrame runs as
separate programs. They are built by tools/ffmpeg in the CloakFrame repository
from FFmpeg 9.0.2 (https://ffmpeg.org/) with x264 and x265 statically linked,
with NVIDIA's NVENC headers on Windows and Linux, and with Intel's libvpl
statically linked on Windows. Built this way, ffmpeg and ffprobe are licensed
under the GNU General Public License, version 2 or later, whose text is at the
end of this section; CloakFrame's Apache License 2.0 does not apply to them. The
licenses of their parts and their exact build configuration (BUILDINFO.txt) are
in the FFmpeg folder beside this file in a package.

Their corresponding source, the unchanged upstream archives with the scripts
that build them, is CloakFrame-FFmpeg-9.0.2-1-source.tar. It is published with
every CloakFrame release that bundles these programs, with the update packages,
and at https://github.com/nyabi-gh/CloakFrame/releases/tag/ffmpeg-9.0.2-1
