## 安装程序与自动更新

- Windows 以 `CloakFrame-Windows-x64-Setup.exe` 发布。按用户安装，不会请求管理员
  权限。
- Linux 以支持自更新的 `CloakFrame-Linux-x86_64.AppImage` 发布。
- macOS 使用固定名称 `CloakFrame-macOS-arm64.dmg`。
- 从这个版本开始，在 Windows 和 Linux 上同意更新后会就地下载并应用。从下一个版本
  起只下载增量部分。
- macOS 继续提供已签名并公证的 DMG，今后通过 Sparkle 安装更新，而不再打开发布页面。
- 同意方式不变。启动时的检查可以在设置中关闭，更新文件只在你选择 **更新** 之后才会
  下载。

## 新的人脸模型

- 照片和视频推荐使用的高精度模型为 YOLO5Face-n。
- 新增轻量 CPU 模型 YuNet，下载不到 0.3 MB。
- 仍然可以通过 **浏览…** 使用自定义的 SCRFD ONNX 文件。

## 用自选图片遮盖

- 可以选择 PNG、JPEG、BMP、TIFF、WebP 图片，在照片、视频、样式预览和图片审阅中覆盖
  人脸与车牌。
- 保持图片的宽高比；在提供关键点的模型下，覆盖图会随人脸倾斜角度旋转。
- 沿视频轨迹对位置、大小和倾斜进行插值并平滑衔接。
- 透明部分下方会先铺一层马赛克，因此透明像素不会透出原始区域。

## webm 输入

- 除已支持的格式外，还可以放入 `.webm` 文件。支持 VP8 与 VP9 视频。输出仍然是
  H.264 或 HEVC 的 MP4，Opus 与 Vorbis 音频会转换为 AAC。

## 视频审阅

- 编码前可以把漏检的区域画成手动轨迹。
- 可以把手动轨迹限制在需要的时间范围内。
- 目标移动时可以添加关键帧，并在关键帧之间插值。
- 可以删除手动轨迹，或继续排除误检的自动轨迹。

## 不再隐藏未遮盖的区域

- 检测器因安全上限而丢弃的候选、因置信度低被删除的轨迹，以及轨迹内部无法插值的
  空档，现在都会计入结果。只要还有残留，任务就会以 **需要检查** 而不是 **完成**
  结束，并在摘要中给出数量。
- 置信检测较少的视频轨迹默认也会被包含。要排除它，需要在审阅界面中明确取消勾选。
- 单张照片中人数过多、检测数量超过上限时，也会给出警告，而不是悄悄丢弃。

## 视频的还原度

- 检测、审阅与编码共用同一条时间轴。即使视频流比容器起始得晚，审阅中看到的画面
  也正是最终编码的画面，音频同样按相同区间裁剪。
- 保留非方形像素（变形宽银幕）视频的显示宽高比。
- 保留全部音频轨道。此前只有第一条能保留，解说和其他语言的轨道会悄悄丢失。语言
  标记同样会保留。
- 当解码器通过丢帧从损坏的视频中恢复时，不再把变短或损坏的结果当作正常完成保存，
  而是报告失败。
- 硬件编码器在实际编码过程中失败时，会改用软件编码器重试一次，而不是让整个任务
  失败。
- 相隔仅几帧的两次镜头切换现在都能检出。此前第二次会在确认第一次的过程中被吞掉，
  马赛克可能越过该边界继续漂移。短于两帧的镜头——单帧插入，或两个场景之间的
  闪光——仍会报告为一个边界。

## 稳定性

- 单张图片所需内存超过上限时，会在解码前跳过并说明原因。此前会继续处理，可能导致
  内存不足。
- 点击 **开始** 之后立刻按下的 **停止** 不会再被忽略。
- 系统资源不足、无法创建工作线程时，应用不会再突然退出。
- 对带有 Alpha 通道的图片使用纯色遮盖时，会填充为不透明的黑色。
- 在不支持原子重命名的存储（FAT、exFAT、部分网络共享）上保存时，中途中断也不会留下
  看起来像成品的残缺文件。
- 在 Windows 上使用非 ASCII 路径时，元数据保留同样有效。
- 原有设置中的“快速／精确”选择会沿用到新的模型配置。
- 限制模型下载大小，并在使用前校验 SHA-256 以及输入输出形状。
- 被强制结束、崩溃或断电中断的任务，此前会把原文件的副本留在原处：照片留在系统
  临时目录，视频留在输出位置旁边。下次启动会清除上一次运行留下的内容，并且只清除
  能确认属于自己、且未在使用中的部分。

## 界面语言

- 视频错误和处理日志的文本现在会以简体中文、韩语和日语显示。此前这些文本在任何
  语言下都只显示英文。

## 模型与许可

- 内置模型仅在首次使用时下载，之后即可离线运行。
- YOLO5Face-n 基于 WIDER FACE 训练数据，应按仅限非商业用途对待。
- YuNet 采用 MIT 许可，自定义 SCRFD 模型遵循其提供方的条款。
