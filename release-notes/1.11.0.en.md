## Installer and automatic updates

- Windows ships as `CloakFrame-Windows-x64-Setup.exe`. It installs per user and
  needs no administrator prompt.
- Linux ships as `CloakFrame-Linux-x86_64.AppImage` with self-update support.
- macOS uses the fixed release asset name `CloakFrame-macOS-arm64.dmg`.
- From this release, accepting an update on Windows or Linux downloads and
  applies it in place, with delta downloads once the next version is out.
- macOS keeps the signed and notarized DMG and installs future updates through
  Sparkle instead of opening the releases page.
- Consent is unchanged. The startup check can be turned off in Settings, and
  updates are downloaded only after you choose **Update**.

## New face models

- YOLO5Face-n is the recommended accurate model for photos and videos.
- YuNet is available as a lightweight CPU model with a download under 0.3 MB.
- Custom SCRFD ONNX files are still available through **Browse…**.

## Custom image overlays

- Choose a PNG, JPEG, BMP, TIFF, or WebP image to cover faces and license plates
  in photos, videos, style previews, and image review.
- The image keeps its aspect ratio, and overlays follow the face tilt reported
  by landmark-capable models.
- Overlay position, size, and tilt are interpolated and smoothed along video
  tracks.
- A mosaic is applied underneath first, so transparent pixels never reveal the
  original region.

## webm input

- Drop `.webm` files alongside the formats already supported. VP8 and VP9 video
  are accepted. The output is still an H.264 or HEVC MP4, and Opus or Vorbis
  audio is converted to AAC.

## Video review

- Draw missed regions as manual tracks before encoding.
- Limit each manual track to the time range where it applies.
- Add keyframes as a region moves and interpolate the boxes between them.
- Remove manual tracks, or keep excluding false automatic ones.

## Uncovered regions are no longer hidden

- Candidates a detector dropped at its safety limit, tracks removed for low
  confidence, and gaps inside a track that could not be interpolated are now
  counted in the result. If any remain, the run ends in **Review required**
  rather than **Done**, and the summary reports how many.
- Video tracks with few confident detections are included by default. Excluding
  one is now an explicit choice in review.
- A photo crowded enough to exceed the detector's limit warns instead of
  silently dropping the extra faces.

## Video fidelity

- Detection, review, and encoding share one timeline. For a video whose stream
  starts after the container does, the frame shown in review is the frame that
  gets encoded, and the audio is cut to the same interval.
- The display aspect ratio of anamorphic (non-square-pixel) video is preserved.
- Every audio track is kept. Previously only the first survived, so commentary
  and alternate-language tracks disappeared silently. Language tags are
  preserved as well.
- When the decoder recovers from a damaged stream by dropping frames, the run
  now fails instead of publishing a shortened or corrupted result as complete.
- If a hardware encoder fails during the real encode, the pass is retried once
  with the software encoder instead of failing the whole item.
- Two shot changes only a couple of frames apart are both detected now. The
  second used to be absorbed while the first was still being confirmed, so a
  mosaic could drift across it. A shot shorter than two frames — a one-frame
  insert, or a flash between two scenes — is still reported as one boundary.

## Reliability

- An image that needs more memory than the budget allows is skipped before
  decoding and the reason is reported, instead of being admitted and risking
  the machine running out of memory.
- **Stop** pressed immediately after **Start** is no longer lost.
- Running out of system resources while starting worker threads no longer
  terminates the application.
- Solid fill is opaque on images with an alpha channel.
- On filesystems without an atomic no-replace rename (FAT, exFAT, some network
  shares), an interrupted publication can no longer leave a truncated file under
  the finished name.
- Metadata preservation now works with non-ASCII paths on Windows.
- An existing Fast or Accurate preference is migrated to the new model choices.
- Model downloads are size-bounded and verified against their SHA-256 digest and
  their input and output shapes before use.

## Language

- Video errors and processing log messages now appear in Korean, Japanese, and
  Simplified Chinese. Until now these messages were shown in English in every
  language.

## Models and licensing

- The built-in models are downloaded on first use and then work offline.
- YOLO5Face-n is based on WIDER FACE training data and should be treated as
  non-commercial only.
- YuNet is MIT-licensed, and custom SCRFD models keep their own upstream terms.
