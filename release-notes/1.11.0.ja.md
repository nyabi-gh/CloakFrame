## インストーラーと自動アップデート

- Windows は `CloakFrame-Windows-x64-Setup.exe` で配布されます。ユーザー単位で
  インストールされ、管理者権限は求めません。
- Linux は自己アップデートに対応した `CloakFrame-Linux-x86_64.AppImage` で配布
  されます。
- macOS は固定名 `CloakFrame-macOS-arm64.dmg` を使います。
- このリリース以降、Windows と Linux ではアップデートを承認するとその場で
  ダウンロードして適用します。次のバージョンからは差分だけを取得します。
- macOS は署名・公証済みの DMG を維持したまま、今後はリリースページを開く代わりに
  Sparkle でアップデートを適用します。
- 同意の扱いは変わりません。起動時の確認は設定でオフにでき、アップデートは
  **更新** を選んだあとにのみダウンロードされます。

## 新しい顔モデル

- 写真と動画で推奨される高精度モデルとして YOLO5Face-n を使用します。
- ダウンロード 0.3 MB 未満の軽量な CPU モデル YuNet を追加しました。
- **参照…** からカスタム SCRFD ONNX ファイルも引き続き利用できます。

## 好きな画像で覆う

- PNG、JPEG、BMP、TIFF、WebP の画像を選んで、写真・動画・スタイルのプレビュー・
  画像レビューで顔とナンバープレートを覆えます。
- 画像の縦横比を保ち、ランドマークに対応したモデルでは顔の傾きに合わせて
  回転します。
- 動画のトラックに沿って位置・大きさ・傾きを補間し、なめらかにつなぎます。
- 透過部分の下にはあらかじめモザイクをかけるため、透明なピクセルから元の領域が
  透けることはありません。

## webm 入力

- これまでの形式に加えて `.webm` ファイルも読み込めます。VP8・VP9 の映像に対応
  します。出力はこれまでどおり H.264 または HEVC の MP4 で、Opus・Vorbis の音声
  は AAC に変換されます。

## 動画レビュー

- エンコード前に、見逃した領域を手動トラックとして描けます。
- 手動トラックを必要な時間範囲だけに限定できます。
- 対象が動く場合はキーフレームを追加し、その間を補間します。
- 手動トラックを削除したり、誤検出の自動トラックを除外し続けたりできます。

## 隠しきれなかった領域を隠しません

- 安全上限のために検出器が捨てた候補、確度が低いとして削除されたトラック、
  トラック内で補間できなかった区間を結果に集計します。ひとつでも残っていれば
  **完了** ではなく **要確認** で終わり、その件数を要約に表示します。
- 確度の高い検出が少ない動画トラックも既定で含めます。除外する場合はレビュー
  画面で明示的にチェックを外す必要があります。
- 1 枚に人が多すぎて検出数が上限を超えた場合も、黙って切り捨てずに警告します。

## 動画の忠実さ

- 検出・レビュー・エンコードが 1 つのタイムラインを共有します。コンテナより
  遅れて始まる映像でも、レビューで見たフレームがそのままエンコードされ、音声も
  同じ区間で切り出されます。
- 正方形でないピクセル（アナモルフィック）の映像でも表示アスペクト比を保ちます。
- 音声トラックをすべて保持します。以前は最初の 1 本だけが残り、コメンタリーや
  別言語のトラックは黙って失われていました。言語タグも保持します。
- 壊れた映像をデコーダーがフレームを捨てて復旧した場合、短くなった結果や破損した
  結果を正常終了として保存せず、失敗として知らせます。
- ハードウェアエンコーダーが実際のエンコード中に失敗した場合、処理全体を失敗
  させる代わりにソフトウェアエンコーダーで一度やり直します。

## 安定性

- 1 枚の画像が使えるメモリの上限を超える場合、デコード前にスキップして理由を
  知らせます。以前はそのまま進み、メモリ不足になるおそれがありました。
- **開始** の直後に押した **停止** が失われなくなりました。
- システム資源が足りず処理スレッドを作れない場合でも、アプリが突然終了しません。
- アルファチャンネルを持つ画像でも、単色で覆うと不透明な黒で塗りつぶします。
- 原子的な名前変更に対応しない保存先（FAT、exFAT、一部のネットワーク共有）でも、
  途中で中断したときに完成品に見える切れたファイルが残らなくなりました。
- Windows で非 ASCII のパスを使ってもメタデータの保持が働きます。
- 既存の設定にある「高速」「高精度」の選択を新しいモデル構成に引き継ぎます。
- モデルのダウンロードサイズを制限し、SHA-256 と入出力の形状を検証してから
  使います。

## 表示言語

- 動画のエラーと処理ログのメッセージが日本語・韓国語・簡体字中国語で表示され
  ます。これまでこれらの文言は、どの言語でも英語のままでした。

## モデルとライセンス

- 内蔵モデルは初回のみダウンロードされ、その後はオフラインで動作します。
- YOLO5Face-n は WIDER FACE の学習データに基づくため、非商用に限って扱って
  ください。
- YuNet は MIT ライセンスで、カスタム SCRFD モデルは提供元の条件に従います。
