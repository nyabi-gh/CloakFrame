Makes sure nothing is saved without the review it promised or with nothing
covered, and tells you about inputs it could not read.

## Review before saving

- A fresh install now starts with **Review before saving** on. The app has
  always asked you to check the result before sharing it, yet the very first
  run started with the check turned off. Turn it off if you do not want it, and
  a setting you have already chosen is left alone.
- If review is on and the review window cannot be shown, nothing is saved and
  the file is reported as failed. Until now the review was skipped, the
  detections were saved exactly as found, and the run could still end in
  **Done**. This applies to photos and videos alike.
- If every region the detector found is excluded and nothing is added in its
  place, you are asked once more before the file is saved. A run that detected
  nothing to begin with is not asked about: a photo with no face in it should
  simply be saved, and prompting every time would teach you to click through
  the one prompt that matters. Video works the same way.

## Inputs that could not be read

- When a folder scan meets a file or folder it cannot read, you are told which
  one and why, and the run ends in **Review required** rather than **Done**.
  Until now they dropped out in silence, and a single error could stop the rest
  of the folder from being scanned at all.
- A path that is no longer there is reported instead of passed over.

## Updates

- An official Windows or Linux build can no longer be published without an
  update signing key.

## Language

- Japanese messages that were still partly in English are fixed. They are the
  lines that say what a run could not do: files skipped, a copy or save that
  failed, FFmpeg errors.
