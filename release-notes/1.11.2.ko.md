작업이 끝난 뒤 어떤 파일을 다시 봐야 하는지 문제 유형별로 찾아갈 수 있고,
영상에서 추적이 끊긴 구간을 순서대로 확인하며 기록을 남길 수 있습니다. 파일을
추가할 때 창이 멈추지 않고, 로컬 로그에는 파일명을 남기지 않습니다.

## 파일별 결과

- 작업이 끝나면 활동 영역의 **파일별 결과…**에서 확인 필요·실패 항목을 문제
  유형별로 걸러 볼 수 있습니다. 미처리 영역, 추적 공백, 자동·사용자 제외 트랙,
  스캔 실패, 메타데이터 경고, 출력 충돌, 처리 실패, 아무것도 가리지 않은 출력을
  나눠서 봅니다. 이전에는 활동 로그를 직접 훑어 문제 파일을 찾아야 했습니다.
- 목록에서 입력 파일을 열거나, 선택한 입력을 다시 검토하거나 재처리할 수
  있습니다. 공백을 선택하면 다시 분석한 뒤 그 프레임에서 영상 검토를 시작합니다.
- 재처리는 **현재 설정**으로 기존 출력 아래 새 작업 폴더에 저장합니다. 원본을
  처음부터 다시 분석하므로 이전 편집은 남지 않습니다. 버튼에도 같은 안내가
  있습니다.
- 출력 폴더 열기는 실제로 저장된 결과에만 쓸 수 있습니다. 결과는 다음 작업을
  시작할 때 초기화되며, 아직 시작하지 않은 파일은 목록에 넣지 않습니다.
- 병렬 처리를 취소해도 이미 실행 중이던 파일의 결과를 빠뜨리지 않습니다.

## 영상 검토

- 검토 전에 발견한 추적 공백을 시작 프레임 순으로 나열합니다. 각 항목은 트랙
  번호와 밀리초 단위 시간, 1부터 시작하는 프레임 범위를 보여 주고, 선택하면 그
  구간의 첫 프레임으로 이동합니다.
- **이전 공백 / 다음 공백**은 현재 위치 앞뒤의 가장 가까운 시작점으로
  이동합니다. 시작점이 같은 공백은 버튼으로 한 번만 지나가며, 목록에서는 각각
  선택할 수 있습니다.
- 좌우 방향키나 타임라인 옆 버튼으로 한 프레임씩 이동합니다. 프레임을 바꾸면
  그리던 박스를 취소해 다른 프레임에 잘못 적용되지 않게 합니다.
- 공백을 모두 살펴본 뒤 **확인 완료**를 체크하면 검토 기록으로 남고, 아직
  확인하지 않은 프레임 수를 따로 볼 수 있습니다. 마스크를 추가·수정·삭제하거나
  트랙 포함 여부를 바꾸면 체크는 초기화됩니다. 확인 완료는 사용자가 봤다는
  기록이며, 그 구간이 실제로 가려졌는지 앱이 검증했다는 뜻이 아닙니다.
- 타임라인의 빨간 표시와 경고는 **검토 전에 발견한** 추적 공백을 뜻합니다.
  수동 마스크를 얹는 것만으로 대상의 실제 위치가 확인되지는 않으므로 경고는
  그대로 남습니다. 공유하기 전에 해당 구간을 직접 재생해 확인해 주세요.
- 저신뢰 트랙 안내를 실제 동작인 기본 포함에 맞게 고쳤습니다. 이전에는 설명만
  기본 제외라고 되어 있어 목록의 체크 상태와 어긋났습니다.

## 결과 요약과 읽지 못한 입력

- 요약에서 검출 제한으로 제외된 영역, 추적 공백 프레임, 제외된 트랙, 메타데이터
  경고가 있는 파일, 읽지 못한 입력 경로를 구분해 표시합니다. 이전에는 하나의
  수치로 합쳐져 무엇이 문제인지 알기 어려웠습니다.
- 접근할 수 없는 하위 폴더를 정확한 경로와 함께 알리고, 읽을 수 있는 다른
  폴더는 계속 훑습니다. 디렉터리 심볼릭 링크는 재귀적으로 따라가지 않습니다.

## 파일을 추가할 때

- 사진과 영상 썸네일을 백그라운드에서 최대 2개씩 만듭니다. 목록에는 기본
  아이콘이 먼저 나타나고 준비되는 대로 채워집니다. 이전에는 영상을 추가할
  때마다 창이 멈춘 것처럼 보일 수 있었습니다.
- 목록에서 지운 항목의 썸네일 결과는 버립니다. 아주 크거나 크기를 알 수 없는
  이미지는 기본 아이콘을 그대로 둡니다. 썸네일을 만들지 않는 것과 본 처리의
  제한은 별개입니다.

## 로컬 로그

- 기본 디스크 로그에 파일명과 경로를 남기지 않습니다. 시작 여부와 결과 수치 같은
  진단 정보만 기록합니다.
- 파일명이 들어갈 수 있는 기록은 **상세 로그**를 직접 켜야 남습니다. 기본값은
  꺼짐이고, 이전에 파일 로그를 켜 두었더라도 상세 기록에 동의한 것으로
  넘겨받지 않습니다.
- 로그 설정은 즉시 적용되며, 설정에서 로그 폴더를 열거나 로그를 지울 수
  있습니다. 삭제는 로그 파일과 순환 로그만 지웁니다. 화면의 활동 내역은 이 디스크
  로그 정책과 별개입니다.

## 모델 다운로드

- 30초 동안 응답이 없거나, 재시도 대기를 포함해 15분을 넘기면 중단합니다.
  일시적인 연결 실패와 HTTP 429·5xx, 시간 초과는 1초 뒤 다시 시도하며 최대
  3회까지 받습니다. 취소는 내려받는 중에도 재시도를 기다리는 중에도 반영됩니다.
- 취소·시간 초과·네트워크 실패·크기 초과·무결성 실패를 구분해 알립니다. 크기와
  무결성 실패는 다시 시도하지 않으며, SHA-256 검증을 통과한 데이터만 저장합니다.
